# Update

!!! danger "Deprecated"

    `UPDATE` is deprecated and **will** be removed in a later version. Please use [EDIT](edit.md) instead.

**Update** is a **deprecated** [global](../extensions/global.md) model declarative command used to change a model instance's attribute.

```ds
UPDATE > [MODEL] > [MODEL-NAME] > [ATTRIBUTE] > [VALUE]
```

*[model declarative]: A model declarative command is a command that performs an operation on a model or a model instance. These commands can usually determine which model they need to access automatically, but in some cases they require the model to be explicitly specified.
