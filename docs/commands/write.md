# Write

!!! note

    The **Write** command cannot be accessed after Ballsdex version 3.0.0.

**Write** is a [file](../extensions/file.md) command used for modifying another file or creating one.

```ds
FILE > WRITE > [PATH] > [ATTACHMENT]
```

- `PATH` - The path you want to write to.
- `ATTACHMENT` - The new contents of the file.

*Requires an attachment.*
